# CBE System
**Computer Based Exam — Sistem Ujian Berbasis Komputer untuk Sekolah**

CBE System adalah aplikasi desktop cross-platform (Linux & Windows) 
untuk mengelola ujian komputer di lingkungan sekolah secara lokal 
tanpa koneksi internet.

## Fitur
- 👨‍🏫 **Dashboard Guru** — Buat soal, kelola ujian, monitor peserta real-time
- 📝 **Bank Soal** — Pilihan Ganda dan Essay
- 🔐 **Exam Mode** — Lockdown penuh saat ujian berlangsung
- 📊 **Hasil Ujian** — Nilai otomatis PG, koreksi manual Essay
- 🌙 **Dark & Light Mode**
- 🌐 **Jaringan Lokal** — Guru sebagai server, siswa konek via token

## Download
Lihat bagian [Releases](../../releases) untuk download installer terbaru.

## Cara Install
**Linux:**
```bash
chmod +x CBE-System-*.AppImage && ./CBE-System-*.AppImage
```

**Windows:**
Jalankan file .exe dan ikuti wizard instalasi.
